# 🤖 Personal Telegram Assistant Bot (Java)

Многофункциональный личный Telegram-бот на Java с поддержкой локального запуска и деплоя в облако (**Render.com** / Docker / Heroku).

---

## 🌟 Возможности

1. **💵 Курсы валют и криптовалют**:
   - Живые курсы фиатных валют (USD, EUR, RUB, KZT) и криптовалют (BTC, ETH, TON, SOL, USDT).
   - Интерактивная кнопка `🔄 Обновить курсы`.

2. **⏰ Напоминания**:
   - Форматы: `/remind 15m Позвонить врачу`, `/remind 2h Учёба`, `/remind 18:30 Купить продукты`.
   - Автоматическая фоновая проверка и уведомление в Telegram с точным текстом.
   - База данных для сохранения при перезапуске (SQLite локально / PostgreSQL на Render).

3. **🎯 Трекер привычек (Habit Tracker)**:
   - Добавление привычек: `/addhabit Выпить 2L воды`.
   - Удобная отметка выполнения прямо через кликабельное инлайн-меню `✅ / ☐`.
   - Подсчет стриков (дней подряд).

4. **🌤️ Утренний отчёт и погода**:
   - Прогноз погоды для любого города (по умолчанию Москва/Алматы) через бесплатный Open-Meteo API (без API-ключей).
   - Автоматическая утренняя рассылка в заданное время (например, в `08:00`) с погодой, привычками на день и курсами валют.

5. **🍿 Парсер новинок и торрентов**:
   - Свежие торрент-релизы, игры и новости технологий с кликабельными ссылками через RSS-ленты.

## 🚀 Быстрый запуск локально

1. Получите токен бота в Telegram у [@BotFather](https://t.me/BotFather).
2. Укажите токен в `config.properties`:
   ```properties
   bot.token=ВАШ_ТОКЕН_ОТ_BOTFATHER
   ```
3. Запустите двойным кликом файл **`run_bot.bat`**.

## ☁️ Деплой на Render.com (Бесплатно)

Бот полностью подготовлен для деплоя на **Render.com**:

### Способ 1: С облачной базой PostgreSQL (Рекомендуется, 1-Click)
1. Загрузите код бота в ваш GitHub-репозиторий.
2. Зайдите на [Render.com](https://render.com) -> **New** -> **Blueprint**.
3. Подключите ваш GitHub репозиторий (Render автоматически прочитает файл [`render.yaml`](file:///c:/Users/DVonk/IdeaProjects/untitled/render.yaml)).
4. Укажите переменные окружения `BOT_TOKEN` и нажмите **Deploy**.

### Способ 2: Вручную как Background Worker
1. На Render создайте **New Background Worker**.
2. В качестве среды выберите **Docker** (используется прилагаемый [`Dockerfile`](file:///c:/Users/DVonk/IdeaProjects/untitled/Dockerfile)).
3. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN`: Токен вашего бота.
   - `USER_CHAT_ID`: Ваш Chat ID в Telegram (бот сам его определит при первом `/start`).
   - `DATABASE_URL`: (Опционально) Ссылка на бесплатную базу данных PostgreSQL на Render.

## 🛠️ Переменные окружения (Environment Variables)

| Переменная | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| `BOT_TOKEN` | Токен Telegram бота | Из `config.properties` |
| `USER_CHAT_ID` | Telegram Chat ID владельца | Из `config.properties` / auto |
| `DATABASE_URL` | Ссылка на PostgreSQL DB | SQLite (`data/bot_database.db`) |
| `WEATHER_CITY` | Город для погоды | Москва |
| `MORNING_REPORT_TIME`| Время утреннего отчёта | 08:00 |

## 📱 Команды в Telegram

- `/start` — Запуск и открытие главного меню
- `/help` — Справка по всем командам
- `/rates` — Посмотреть курсы валют и крипты
- `/remind 15m Текст` — Установить напоминание через 15 минут
- `/remind 18:30 Текст` — Напомнить в 18:30
- `/reminders` — Список активных напоминаний
- `/addhabit Название` — Добавить новую привычку
- `/habits` — Трекер привычек и отметка
- `/weather` — Текущая погода
- `/torrents` — Свежие новинки торрентов/игр
- `/morning` — Вызвать утренний отчёт вручную
